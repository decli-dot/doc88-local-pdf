# DecliPDF — локальная версия

**Обозначение документа → готовый PDF с поиском по тексту.**

## Запуск

Один раз запустите `Setup.cmd`, затем открывайте программу через `Start.cmd`.
Страница программы: [127.0.0.1:8968](http://127.0.0.1:8968/).
Нужен Node.js 24. Результаты остаются на этом компьютере.

## Поиск

| Запрос           | Результат                                                                              |
| ---------------- | -------------------------------------------------------------------------------------- |
| `ISO 17450`      | Окно со всеми найденными частями серии: отметьте нужные или нажмите **«Выбрать все»**. |
| `ISO 17450-3`    | Уточнение опубликованного издания выбранной части.                                     |
| `ISO 129-1:2015` | Если такого издания нет, выбор из существующих изданий.                                |
| `DIN 5008`       | Проверка обозначения, даты, полного названия и объёма по DIN Media.                    |
| `ASME Y14.5`     | Проверка по ASME; год издания и год подтверждения учитываются отдельно.                |
| `EN 14420`       | Выбор частей серии EN с учётом опубликованных поправок; проекты не предлагаются.       |

Для выбранных частей создаётся одна очередь. Готовые документы можно скачать одним ZIP.
Подтверждение доступа выполняется вручную, когда программа его запрашивает.

В обычном окне программа сначала проверяет варианты Doc88. Если подходящий документ не найден или источник недоступен, поиск продолжается в Anna’s Archive. Если проверенный документ получен из первого источника, второй не открывается. Год издания, выбранный язык и проверки страниц сохраняются при переходе.

Ход работы показан тремя этапами: **«Уточняем издание» → «Проверяем документ» → «Готовим PDF»**. Если обработка прервалась, сообщение различает отсутствие документа, проблему доступа, неподходящий язык, сокращённый документ и несовпадение издания. Предлагаемое действие повторяет тот же запрос, позволяет проверить обозначение или выбрать другой доступный язык того же стандарта. Другое издание автоматически не подставляется.

## Языки и текст

- **RU / EN** переключает интерфейс.
- В основном окне показана строка **«Язык документа»**. Улучшение изображений включается автоматически; ручной переключатель и список моделей OCR доступны только в dev-режиме.
- ISO, ASME и BS используют английский. Для DIN можно выбрать английский или немецкий, для NF — английский или французский, для EN — английский, немецкий или французский. Если каталог указывает один доступный язык, выбор выполняется автоматически. Проверяется именно выбранный язык.

- Страницы PDF с готовым текстом сохраняются; страницы-сканы проходят OCR.
- Кнопка **«Текст документа»** открывает текст для удобного копирования: убирает лишние переносы строк, осторожно соединяет разорванные слова, учитывает простые колонки и таблицы. Изображения страниц и текст, используемый для проверки документа, остаются прежними.

При выборе нескольких частей серии язык задаётся один раз для всего списка. Если у отдельной части выбранный язык отсутствует по данным каталога, программа уточняет язык только для неё. Для остальных частей общий выбор сохраняется. Выбранные части и незавершённый выбор языка сохраняются после закрытия программы.

Существенные замечания к готовому PDF видны всем: неуверенная нумерация, слабое распознавание и страницы без распознанного текста. Ссылки открывают соответствующие листы PDF. Если для старого результата известна только общая неопределённость, доступна ссылка на документ целиком; конкретная проблемная страница не придумывается. Замечание само по себе не означает, что страница пропущена.

## Обозначения и проверка

Короткие запросы `DIN 129-1`, `BS 129-1` и `NF 129-1` учитывают варианты EN и EN ISO. Полное обозначение уточняется по каталогу; неоднозначные варианты предлагаются для выбора.

DIN, BS и NF проверяются по каталогу DIN Media; ASME — по ASME. Дополнительный каталог EN Standards используется при недоступности основных данных. Источник метаданных указывается в карточке издания.

Сначала программа ищет полное обозначение с годом, например `ISO 129-1:2018`, и проверяет кандидатов с совпадающим обозначением и изданием. Если подходящий PDF не найден, автоматически запускается расширенный поиск: другие варианты записи и обозначение без года. На обоих этапах год издания проверяется по самим страницам, а для английских документов отдельно проверяется письменность изображений, чтобы китайский скан не считался английским из-за ошибок OCR.

До полной обработки программа проверяет объём по карточке, затем первые страницы: обозначение, год, язык текста и письменность изображений. При готовом исходном тексте OCR для этой проверки не нужен. Заголовки с китайскими приписками, пометками AI или лишней пунктуацией сами по себе не отклоняются. После неудачных кандидатов поиск продолжается на следующих страницах и с другими вариантами записи обозначения.

Поиск следует ссылкам на следующие страницы, даже если текущая страница содержит мало результатов, повторы или только неподходящие документы. Он заканчивается после получения проверенного PDF либо исчерпания доступных результатов. Если доступ или обработка прервались, программа сообщает, что поиск не завершён, и предлагает продолжить. Наличие подходящего документа в источнике не гарантируется.

Если загруженный исходный PDF оказался сканом, OCR использует уже сохранённые страницы. Повторное скачивание того же документа для распознавания не требуется.

Повторный поиск того же издания на том же языке использует проверенные страницы и готовый PDF из локального кэша. Каталог издателя проверяется перед обращением к кэшу: новый год издания не заменяется старым результатом. Файлы проверяются по контрольным суммам, а PDF — по фактическому числу страниц. При повреждении готового результата используются только целые сохранённые материалы; документ снова проходит проверки. Замечания к качеству и структура PDF сохраняются.

Серия EN определяется по европейским обозначениям в каталоге DIN Media — национальная дата DIN не подставляется вместо года EN. Число страниц национальной адаптации не используется как объём EN. Если независимый объём EN неизвестен, приложение сообщает об этом; проверка загрузки всех заявленных страниц источника сохраняется. Для ISO, DIN, BS, NF и ASME сверка объёма с каталогом остаётся обязательной.

В обычном интерфейсе доступны поиск по обозначению и список документов. «Последние документы» и подробные результаты проверок видны только в dev-режиме. Вкладки ввода ссылки и архива убраны. В шапке показана поддержка ASME, BS, DIN, EN, ISO и NF в алфавитном порядке.

Libgen и Anna’s Archive отключены от рабочего поиска. Их подключение отложено.

Способ обработки выбирается автоматически: сначала программа пробует получить PDF с исходным текстом. При необходимости отдельные страницы распознаются через OCR; при технической неудаче используется обработка изображений. Проверки языка, издания и объёма сохраняются. Пустые страницы и чертежи с небольшим количеством текста не отправляют весь документ на повторное распознавание.

Предварительная проверка выполняется для двух кандидатов одновременно, если в текущей порции результатов есть несколько подходящих вариантов. Порядок выбора сохраняется: более быстрый ответ не обгоняет предыдущий подходящий документ. Документы обрабатываются по одному; внутри OCR несколько страниц могут распознаваться одновременно. Подтверждение доступа выполняется в основном задании. После получения проверенного PDF или остановки задания ненужные проверки отменяются; программа дожидается их завершения.

OCR автоматически выбирает до четырёх параллельных задач установленного движка или до двух встроенного, учитывая доступные процессоры и память. Итоговые страницы сохраняют исходный порядок. PDF сжимается без потерь пикселей и цветов. На 154 страницах ISO 1101 обработка сохранённого архива сократилась с 6 мин 31 с до 2 мин 27 с, размер файла — с 400 до 321 МБ. [Подробности замера и проверки качества](OCR-PERFORMANCE.md).

Обновления относятся к локальной программе и не опубликованы на GitHub Pages.

<summary>Для разработчика</summary>

Dev-режим открывается сочетанием **Ctrl+Shift+D**. Требуется настроенный локальный пароль; пароль не поставляется с исходным кодом. Для смены пароля передайте его через стандартный ввод скрипту `scripts/dev-password.cjs` и перезапустите программу. Сохраняется только солёный хеш. Сеанс завершается кнопкой выхода или через час.

В блоке **«Время обработки»** показаны каталог, поиск, предварительная проверка, загрузка, OCR, сборка PDF, проверка документа и ожидание подтверждения доступа — только те этапы, которые выполнялись. Это время текущей попытки, без ожидания в очереди. У параллельных этапов периоды могут пересекаться; их нельзя складывать для вычисления общего времени. В закрытых диагностических данных отдельно сохраняется суммарное время работы (`workMs`) и время без двойного счёта пересечений (`wallMs`). Эти сведения не выдаются обычным API.

Обычный API не возвращает промежуточные варианты, адреса источников и диагностические сообщения. Dev-режим показывает их после входа.

В dev-режиме доступен список **«Способ обработки»**: «Автоматически», «Прямое извлечение», «Изображения + OCR». Новые задания после выхода из dev-режима используют автоматический выбор. Для прямого извлечения нужна Java; если она отсутствует, автоматический режим использует OCR. Подробности: [EXPERIMENTAL-DIRECT.md](EXPERIMENTAL-DIRECT.md), [результаты проверки](ENGINE-VALIDATION.md).

Проверки: `npm test`, `npm run test:interface`, `npm run check`.

В списке **«Источники документов»** доступны четыре режима: **«Все — сначала Doc88»**, **«Все — сначала Anna’s Archive»**, **«Только Doc88»**, **«Только Anna’s Archive»**. Выбор сохраняется в браузере, передаётся новым заданиям, спискам и частям серии; при продолжении задания используется сохранённый в нём режим. После выхода из dev-режима новые запросы снова используют Doc88 первым. Кэш готовых результатов Doc88 не обходит выбор Anna’s Archive первым или единственным источником.

В dev-режиме также остаётся отдельный [инструмент проверки карточки Anna’s Archive](EXPERIMENTAL-ANNA.md). Ручное подтверждение для любого источника появляется в основном окне.

Результаты полного прогона на ISO 1101, DIN 129-1, ISO 17450 и ASME Y14.3: [проверка локального сценария](WORKFLOW-VALIDATION.md).

Общий кэш хранится в `.data/document-cache`, отдельно от списка заданий. Ключ включает полное обозначение, дату издания и подтверждения ASME, язык, способ обработки, улучшение изображений, название и объём из каталога. Допускаются только документы с подтверждёнными языком, письменностью, изданием и полным объёмом; неопределённый язык не подходит. Старые задания без этих доказательств повторно не используются. Пароли, профили браузера и диагностические журналы в кэш не копируются. Очистка окна скрывает задания, сохраняя файлы для повторного поиска. Автоматического удаления кэша пока нет.

Проверка общего кэша на ASME Y14.6-2001 (R2025): второй отдельный запрос — около 1,9 с вместе с повторным обращением к каталогу; 28 страниц, 35 пунктов структуры, PDF побайтно совпал с проверенным результатом. Это замер повторного поиска на этом компьютере; первичная загрузка и OCR зависят от документа и доступа к источнику.
