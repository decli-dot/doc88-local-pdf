# Проверка правок из Word

Локальная проверка 7 ноября 2026 года. GitHub и опубликованный сайт не изменялись.

## Изменения

- Выбор языка после уточнения издания. ISO, ASME и BS используют английский; DIN — английский/немецкий; NF — английский/французский; EN — английский/немецкий/французский. Варианты сужаются по сведениям каталога, когда они доступны.
- Проверка языка соответствует выбору пользователя. Подпись проверки в dev-режиме также показывает выбранный язык.
- Объём проверяется до загрузки; затем анализируются первые девять страниц, включая язык и год. Для сканов OCR применяется к выборке страниц. Неуверенная предварительная проверка не заменяет полную проверку документа.
- Поиск продолжается после неподходящих вариантов, по следующим страницам и вариантам записи обозначения. Варианты с другим языком в заголовке не отклоняются без проверки содержимого. Пунктуация и отсутствие пробелов допустимы.
- EN 14420 открывает выбор частей серии. Европейский год берётся из ссылки на EN в каталоге DIN Media, а не из даты национальной адаптации. Проекты исключены.
- В шапке — «Поддержка» и логотипы ASME, BS, DIN, EN, ISO, NF. «По ссылке» и «Из архива» скрыты во всех режимах. История доступна только в dev-режиме.
- OCR может использовать уже полностью загруженный PDF-скан, без повторного обращения к источнику. Локальная копия проверяется по контрольной сумме.

## Реальные примеры

| Пример                                      | Наблюдаемый результат                                                                                                                                                                          |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ISO 17450-4:2017                            | Найдены варианты с лишней пунктуацией, включая «（正版） ISO 17450-4-2017 .». Получен PDF на 22 страницы, каталог ISO — 15. Английский, обозначение, год и загрузка всех страниц подтверждены. |
| DIN 129-1                                   | Каталог уточнил DIN EN ISO 129-1:2022-02, доступны английский и немецкий.                                                                                                                      |
| Немецкий DIN 276:2018-12, выбор английского | Предварительная проверка отказала с FOREIGN_LANGUAGE до полной обработки.                                                                                                                      |
| Тот же DIN 276, выбор немецкого             | Первые страницы подтвердили немецкий и нужное издание. OCR понадобился для двух обложек, основной текст прочитан напрямую.                                                                     |
| EN 14420                                    | Каталог вернул восемь опубликованных частей, включая действующие поправки. Проект части 7 с датой 2025 не включён.                                                                             |

Для ISO 17450-4 дополнительно проверены извлекаемый текст итогового PDF и изображения обложки/основной страницы. Нумерация по OCR осталась неуверенной; приложение сохраняет соответствующее диагностическое замечание.

## Ограничение EN

Каталог национальных адаптаций не даёт независимого числа страниц исходного EN. Программа не подставляет объём DIN вместо EN: сохраняет проверку всех заявленных страниц источника и показывает пользователю, что объём EN по каталогу не подтверждён. Для остальных поддерживаемых издателей обязательная сверка объёма сохранена.

Материалы контрольных запусков находятся в игнорируемой `.data/revision-review/`. Для повторения: `node scripts/review-revisions.cjs --validate`, `--process-iso`, `--din-preview`, `--qa`. Эти команды работают с отдельной папкой проверки и не добавляют документы в историю пользователя.
