# Автоматический выбор обработки: локальная проверка

Проверено 7 ноября 2026 года. Обновление не публиковалось.

| Запрос     | Издание по каталогу     | Страниц в результате | Способ                                             | Отдельно распознано |
| ---------- | ----------------------- | -------------------: | -------------------------------------------------- | ------------------: |
| ISO 5459   | ISO 5459:2024           |                  124 | Прямое извлечение                                  |                   0 |
| ASME Y14.3 | ASME Y14.3-2012 (R2024) |                   99 | Прямое извлечение с OCR отдельных страниц          |                   9 |
| DIN 276    | DIN 276:2018-12         |                   56 | Прямое извлечение с OCR обложки и следующего листа |                   2 |

Объём по каталогам — соответственно 115, 96 и 56 страниц. Первые два файла включают дополнительные обложки и вводные листы. Число ресурсов источника совпало с числом страниц PDF. Язык, обозначение, год основного издания и объём прошли проверку во всех трёх случаях. Для ASME год переутверждения берётся из каталога; дата основного издания 2012 подтверждается внутри документа.

Печатная нумерация ISO прошла автоматическую проверку. Для ASME и DIN анализатор оставил предупреждение о ручной проверке нумерации: результат не выдаёт её за доказанную.

## Что проверено дополнительно

- Обычный интерфейс создаёт задания в режиме `auto`, даже если в dev-режиме раньше был выбран другой способ.
- Ручной режим доступен после входа в dev-режим; публичные запросы с `direct` или `ocr` отклоняются сервером.
- При технической неудаче прямого извлечения автоматический режим вызывает обработку изображений один раз.
- Неподходящая письменность, язык, другое издание, неполнота и отмена не переключаются на OCR для обхода отклонения.
- OCR отдельных страниц сохраняет порядок, размеры страниц и исходный текст остальных листов.
- Разделённые пробелами цифры ASME корректно проверяются; ссылки на заменённые издания и историю публикаций не подменяют обозначение обложки.
- При сборке PDF объединяются только потоки с совпадающими байтами **и словарями параметров**. Разные параметры декодирования не объединяются.
- Проверены RU/EN, скрытие настроек, выход из dev-режима и отсутствие горизонтального переполнения на мобильной ширине.

Каталоговый адаптер ISO отдельно проверен через обычную минимизированную браузерную сессию — такой режим используется локальной программой. Запрос ISO 5459 автоматически уточнился до ISO 5459:2024, 115 страниц, и нашёл источник на 124 листа. Метаданные сверены с [официальной страницей ISO](https://www.iso.org/standard/87855.html). Записи ASME и DIN также получены обычными каталоговыми адаптерами.

Повторные испытания использовали проверяемые промежуточные файлы, поэтому их время не является замером полной обработки с нуля. Ускорение для этих трёх стандартов не заявляется в числах.

Подробные отчёты и PDF хранятся в `.data/engine-validation/{iso-5459,asme-y14-3,din-276}/auto/`, вне публикуемых файлов. Скрипт `scripts/validate-engines.cjs` предназначен для повторения локальных испытаний.
