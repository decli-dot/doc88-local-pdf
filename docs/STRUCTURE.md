# Структура документа

Разделы, подразделы, приложения и библиография определяются по тексту и расположению заголовков на страницах. Оглавление помогает проверить обозначения и названия; переходы привязываются к найденным заголовкам в основном тексте, а не к предположительному смещению печатных номеров страниц.

- Текст разных колонок анализируется раздельно. Подразделы упорядочиваются по обозначению и прикрепляются к соответствующему разделу.
- Колонтитулы, номера страниц, сведения об авторском праве, списки рисунков/таблиц и пронумерованные абзацы без самостоятельного заголовка исключаются.
- Названия, перенесённые на следующую строку, объединяются. Разделы из оглавления получают название по оглавлению после проверки заголовка в основном тексте.
- Учитываются английские, немецкие и французские обозначения оглавления, приложений и библиографии.
- Если заголовки нарисованы и отсутствуют в текстовом слое, применяется отдельное распознавание таких областей. Его результаты кешируются. Основной текст OCR и изображение страницы не заменяются.
- PDF получает новое дерево навигации с переходами к высоте заголовка на странице. Предыдущее дерево заменяется целиком, включая случай, когда надёжные заголовки не найдены.

Восстановление остаётся зависимым от качества исходника. Пункты оглавления без уверенно найденной страницы не получают выдуманный адрес; в таком случае показывается замечание.

## Проверка 8 ноября 2026 года

| Документ                | Проверка                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| ASME Y14.6-2001 (R2025) | Вместо прежних 62 пунктов получены 35 заголовков. Все заголовки разделов из оглавления нашли страницы. Проверены все 35 PDF-переходов. |
| ISO 17450-4:2017        | Разделы, определения с вложенной нумерацией, приложение A и библиография привязаны к основному тексту.                                 |
| DIN 276:2018-12         | Восстановлены нарисованные немецкие заголовки: разделы 1–6, определения, подразделы и Literaturhinweise.                               |

Для ASME изображения пяти страниц (обложка, основной текст, таблицы и иллюстрации) до и после изменения навигации совпали по пикселям; число страниц сохранилось.

Автоматические проверки: `node --test tests/structure.test.cjs tests/document-features.test.cjs`. Проверка сохранённых реальных примеров: `node scripts/validate-structure.cjs`, для DIN — с `--din`.

`node scripts/rebuild-structures.cjs --id UUID` создаёт проверочную копию с новой структурой в `.data/structure-review/`. Параметр `--apply` обновляет готовый результат, предварительно сохраняя исходный PDF и метаданные в `.data/structure-backups/`. Для всех готовых результатов используется `--all`; обновление выполняется при остановленной обработке.
