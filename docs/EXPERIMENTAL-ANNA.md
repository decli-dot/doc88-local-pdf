# Anna’s Archive — готовый PDF

Anna’s Archive подключён к общему поиску локальной программы. В обычном окне сначала проверяется Doc88, затем, если подходящий документ не найден, Anna’s Archive. Проверки издания, выбранного языка и страниц применяются к обоим источникам. Получение PDF проверено на **ISO 129-1:2018**.

В dev-режиме список **«Источники документов»** позволяет выбрать порядок двух источников или оставить только один. Выбранный режим применяется к обычной кнопке поиска, списку документов и частям серии. Режим задания сохраняется при продолжении после остановки. Названия источников и их диагностические данные скрыты в обычном интерфейсе.

## Проверка отдельной карточки

Для обычного поиска достаточно основного поля обозначения документа. Отдельный инструмент ниже сохранён для диагностики и проверки известной карточки ISO:

1. Откройте локальную программу, нажмите **Ctrl+Shift+D** и войдите с настроенным паролем.
2. Разверните **«Эксперимент: поиск готового PDF»**. Укажите только обозначение ISO, например **ISO 129-1**.
3. Нажмите **«Найти готовый PDF»**. Программа уточнит издание по каталогу ISO, найдёт карточки и проверит PDF по порядку до подходящего результата или исчерпания доступной выдачи.
4. Если сайт запросит подтверждение, выполните его в блоке **«Подтверждение доступа»**. Изображение можно увеличить; для текстовой проверки доступны ввод ответа и кнопка Enter.

Блок **«Указать карточку вручную»** необязателен. В нём можно задать адрес вида `/md5/…` и страницу **Slow Partner Server** той же карточки. Временную прямую ссылку на файл вставлять не нужно.

После подтверждения программа получает свежую ссылку, скачивает PDF и проверяет его. Обычно подтверждение выполняет человек; программа передаёт его действия. Локально можно включить [эксперимент RuCaptcha](CAPTCHA.md) для текстовой капчи DDoS-Guard: он ограничивает платные попытки и сохраняет ручное подтверждение при неудаче. Ожидание проверки ограничено десятью минутами. При прерывании можно повторить попытку.

В каждом источнике сначала выполняется поиск по полному обозначению с годом, затем — по вариантам записи номера. Просматриваются следующие страницы выдачи. Первый источник проверяется до перехода ко второму; готовый проверенный PDF завершает поиск. Подпись карточки используется для отбора кандидатов; окончательное решение об издании принимается по самому PDF. Для ISO отбрасываются национальные издания; для DIN, BS, NF, EN и ASME сохраняется обозначение, уточнённое в каталоге. Другие части, отдельные поправки вместо основного стандарта и явно неподходящий язык отбрасываются. Упоминание нужного стандарта в описании другого документа не считается совпадением.

## Что сохраняется

- PDF с готовым текстовым слоем сохраняет исходные страницы. OCR применяется к страницам, которым требуется распознавание.
- Проверяются обозначение и издание внутри документа, выбранный язык, объём по каталогу издателя и последовательность страниц. Отдельно проверяется письменность на изображениях выбранных страниц.
- Файл должен совпасть с MD5 выбранной карточки. Сохранённый исходник дополнительно проверяется по SHA-256 при повторном использовании.
- PDF получает официальное полное название; структура и нормативные ссылки обрабатываются общей системой программы.

Исходник и результат остаются в каталоге задания. Временная ссылка скачивания не записывается в задание или кэш документов. Уже скачанный исходник той же карточки можно повторно использовать из другого локального задания: перед копированием сверяются SHA-256, MD5 и число страниц, после копирования снова проверяется содержание. Повреждённые файлы пропускаются. Общий кэш готовых результатов обычного поиска этим экспериментом не пополняется.

В пределах одного задания поиск, карточки и скачивание используют один обычный сеанс браузера. Это сохраняет состояние сайта между этапами; сам сайт всё равно может потребовать новое подтверждение.

## Границы прототипа

Поддерживается домен `annas-archive.pk`; отдельный диагностический инструмент работает с обозначениями ISO. Перебор разных партнёрских серверов ещё не включён. Доступность сайта и длительность ожидания зависят от источника; полностью автоматическое бесплатное скачивание без ручной проверки не гарантируется. Libgen остаётся отключённым.

Общий поиск также передаёт в Anna’s Archive обозначения DIN, BS, NF, EN и ASME и выбранный в программе язык. Отбор национальных обозначений и английского, немецкого и французского языков проверен на локальных тестовых карточках; живой прогон описан выше только для ISO. Тесты переключения источников проверяют порядок, продолжение после отказа, остановку, сохранение режима и отсутствие обращений к отключённому источнику.
