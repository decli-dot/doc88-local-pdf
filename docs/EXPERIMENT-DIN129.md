# Проверка прямого модуля: DIN 129-1

Дата проверки: 7 ноября 2026 года. Локальный эксперимент, без подключения к основному поиску.

Запрос `DIN 129-1` уточнён по каталогу до **DIN EN ISO 129-1:2022-02**, 83 страницы. Автоматический поиск нашёл три варианта и выбрал для эксперимента тот же источник, который использовался в сохранённом запуске прежней обработки.

## Измерения

| Показатель                 | Прежняя обработка |                        Прямой эксперимент |
| -------------------------- | ----------------: | ----------------------------------------: |
| Страниц                    |                83 |                                        83 |
| Получение страниц          |       около 108 с |                                      48 с |
| Подготовка PDF с проверкой |  около 4 мин 03 с |                                2 мин 19 с |
| Размер PDF                 |           45,8 МБ |                                   10,3 МБ |
| Распознавание              |  OCR всех страниц | Не потребовалось: исходный текст сохранён |

Для нового запуска: открытие страницы — 8,1 с, получение ресурсов — 47,8 с, конвертация в трёх процессах — 51,7 с, проверка PDF — 27,9 с; оставшееся время заняла сборка и завершение этапов.

Сравнение ориентировочное: прежнее время восстановлено по сохранённым файлам того же источника, новый запуск измерен отдельно. Прежний интервал начинается с первой сохранённой страницы; новый включает открытие страницы. Поиск по каталогам и первичная подготовка конвертера не учитываются. Это не серия повторных замеров в одинаковых сетевых условиях.

Сетевое время заметно менялось: отдельный ранний прогон получил ресурсы за 18,5 с; ещё один запуск оборвался на сетевой ошибке. Поэтому ускорение загрузки не следует считать постоянным. Финальный полный запуск завершился без сетевых повторов.

## Проверка результата

- Получены и преобразованы все 83 ресурса страниц; для каждого записана контрольная сумма.
- Объём совпал с каталогом издателя.
- Немецкий текст и обозначение издания 2022-02 подтверждены внутри PDF.
- На всех 83 страницах присутствует извлекаемый исходный текст.
- Выборочно просмотрены обложка, основной текст и страницы с чертежами. Исправлено отображение табуляции как квадратиков на обложке.
- Созданы структура PDF и отдельный текстовый файл.
- Общая автоматическая проверка печатной нумерации осталась неуверенной: существующий анализатор ориентирован на характерные подписи ISO. Подтверждённый объём не следует трактовать как независимую проверку каждого печатного номера.
