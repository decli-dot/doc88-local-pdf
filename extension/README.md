# Doc88 → OCR PDF · расширение 1.9

## Один раз установить

1. Распакуйте ZIP в постоянную папку. Не удаляйте её после установки.
2. Откройте `edge://extensions` в Edge или `chrome://extensions` в Chrome.
3. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
4. Выберите папку, в которой находится `manifest.json`.
5. Обновите уже открытые вкладки Doc88 и конвертера.

## Получить PDF

Откройте [программу](https://decli-dot.github.io/doc88-local-pdf/) и введите название ISO, ссылку Doc88 или список документов. На странице работают проверка издания и объёма, очередь, подготовка изображений, структура PDF, нормативные ссылки и поправки. По завершении нажмите «Скачать OCR PDF».

Можно также нажать «Скачать OCR PDF» на самом документе Doc88 или значок расширения. Открытая вкладка программы используется повторно. Если Doc88 попросит капчу, передвиньте ползунок в панели программы. Если браузер запретил панель, выполните проверку во вкладке Doc88.

Для обновления замените файлы в папке расширения, нажмите значок обновления на его карточке в `chrome://extensions` / `edge://extensions` и обновите программу. При переходе с 1.2 подтвердите новые доступы к ISO и панели ручной проверки.

Изображения не отправляются на сервер. Модель английского OCR и программы распознавания загружаются с GitHub Pages. Для первого запуска нужен интернет. После распознавания исходные изображения можно отдельно сохранить в ZIP.

Предел браузерной версии: 500 страниц, суммарно 250 МБ изображений. Для очень больших документов есть локальная версия в репозитории.

## Доступы

`storage` хранит сведения о текущей передаче и собственных вкладках расширения. `scripting` читает публичные данные каталога ISO. `debugger` получает изображение активной ручной проверки Doc88 и передаёт в неё движения пользователя. Команды принимаются только от страницы программы; адреса и принадлежность вкладок проверяются. Отладчик отключается после подтверждения или отмены.

Изображения, распознанные страницы и PDF сохраняются в IndexedDB страницы программы. После перезагрузки можно продолжить прерванную загрузку и OCR. Очистка данных сайта удалит историю и файлы. Расширение не читает историю посещений и не собирает аналитику.
