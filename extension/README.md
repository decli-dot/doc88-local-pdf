# Doc88 → OCR PDF

## Один раз установить

1. Распакуйте ZIP в постоянную папку. Не удаляйте её после установки.
2. Откройте `edge://extensions` в Edge или `chrome://extensions` в Chrome.
3. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
4. Выберите папку, в которой находится `manifest.json`.
5. Обновите уже открытые вкладки Doc88 и конвертера.

## Получить PDF

Откройте документ Doc88 и нажмите «Скачать OCR PDF» справа внизу. Расширение автоматически передаст страницы в конвертер https://decli-dot.github.io/doc88-local-pdf/ . После распознавания английского текста PDF скачивается; кнопка скачивания остаётся доступной.

Можно также вставить ссылку в конвертер или нажать значок расширения на открытом документе. Если Doc88 попросит капчу, решите её в исходной вкладке. Не закрывайте вкладки до окончания обработки.

Изображения не отправляются на сервер. Модель английского OCR и программы распознавания загружаются с GitHub Pages. Для первого запуска нужен интернет. После распознавания исходные изображения можно отдельно сохранить в ZIP.

Предел браузерной версии: 500 страниц, суммарно 250 МБ изображений. Для очень больших документов есть локальная версия в репозитории.

## Доступы

Расширение работает только на документах doc88.com и странице конвертера. `storage` хранит в памяти браузера сведения о текущей задаче; изображения и PDF туда не записываются. Закрытие браузера очищает состояние задачи. Расширение не читает историю браузера и не собирает аналитику.
